# baseline

Checkov custom policy baseline for Terraform estates

Generated by repave blueprint `checkov-policy-generic`.

## Standard

This repository follows `standards/policy/checkov.md` v1.0.0 and the
shared governance baseline in `standards/policy/governance-baseline.md`.

## Usage

Custom Checkov policies live under `policy/checkov/`. Add pass/fail Terraform fixtures under
`tests/fixtures/` and run:

```bash
checkov -d tests/fixtures/pass --config-file .checkov.yml --external-checks-dir policy/checkov
```

The `checkov` gate runs against the pass fixture at generate/publish time.
